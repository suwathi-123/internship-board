# Internship Board

A responsive internship listing website built using HTML, CSS and JavaScript.

## Live Demo

[View Live Internship Board](PASTE_YOUR_LIVE_URL_HERE)

## Features

- Search internships by role, company and location
- Filter internships by domain
- Responsive design for mobile, tablet and desktop
- Accessible form labels
- Keyboard-friendly navigation
- Empty state for no results
- Error state handling
- Internship details button

## Technologies Used

- HTML5

- JavaScript
- GitHub Pages
